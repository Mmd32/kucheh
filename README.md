# کوچه

بیست بازی کوتاه و مینیمال، فارسی و راست‌چین، در یک وب‌اپ استاتیک بدون بک‌اند.

اسمش را گذاشتیم **کوچه**، چون قدیم‌ها بازی‌مان همین‌جا بود؛ حالا کوچه آمده روی گوشی.

**بازی‌ها:** شطرنج، تخته نرد، منچ، حکم، چهار برگ، بیست‌ویک، نبرد دریایی، مار و پله، مین‌روب، خروج از پارکینگ، لوله‌کشی آب، مار بازی، بیلیارد، نقطه‌بازی، دوز، سودوکو، جدول کلمات، هنگ‌من، هدز آپ و پانتومیم.

## چه چیزهایی دارد

- **بدون سرور و بدون حساب:** هیچ درخواست شبکه‌ای، هیچ کلیدی و هیچ کتابخانه‌ی بیرونی در زمان اجرا نیست.
- **درجه‌ی سختی برای همه‌ی بازی‌ها:** هر بازی سه سطح دارد؛ برای بازی‌های تکی (سودوکو، مین‌روب، پارکینگ، لوله‌کشی، مار، بیلیارد، جدول، هنگ‌من، مار و پله) سطح، اندازه یا قواعد را عوض می‌کند و برای بازی‌های حریف‌دار، هوش کامپیوتر را.
- **چند نفره روی یک گوشی:** حکم، چهار برگ، بیست‌ویک، منچ، مار و پله، نبرد دریایی، هدز آپ، پانتومیم و بازی‌های دو‌نفره. در بازی‌های کارتی دست حریف‌ها پنهان است.
- **تنظیمات:** اعداد فارسی/لاتین، صدا، پوسته‌ی روشن/تیره، اندازه‌ی تخته، کاهش انیمیشن و نام بازیکن.
- **پشتیبان‌گیری:** گرفتن فایل JSON از آمار و بازی‌های ذخیره‌شده و بازیابی دوباره‌ی آن (با اعتبارسنجی کامل).
- **صدا:** همه‌ی افکت‌ها با WebAudio ساخته می‌شوند و فایل صوتی جدا ندارند.

## اجرا

کافی است `index.html` با یک سرور استاتیک سرو شود (ماژول‌های ES با `file://` اجرا نمی‌شوند):

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## تست

موتور بازی‌ها خالص است و بدون مرورگر تست می‌شود:

```bash
npm test
```

تست‌ها شامل perft شطرنج، قواعد تخته نرد، منچ، نقطه‌بازی و مین‌روب، یکتایی جدول سودوکو، سلامت داده‌ی جدول کلمات، حل‌شدن مرحله‌های پارکینگ، اعتبارسنجی و پشتیبان‌گیری داده‌ها، و mount شدن هر بیست بازی روی یک DOM ساختگی است.

## ساختار

- `src/games/<id>/engine.js` — منطق خالص بازی
- `src/games/<id>/index.js` — رابط کاربری همان بازی
- `src/games/registry.js` — فهرست بازی‌ها
- `src/core/` — روتر، ذخیره‌سازی، کارت، رابط مشترک، صدا و کمک‌کننده‌ها
- `src/data/` — کلمات، جدول‌ها، مرحله‌های پارکینگ و راهنمای بازی‌ها
- `scripts/gen-parking.mjs` — تولید مرحله‌های پارکینگ با کمترین حرکت
- `assets/css/` — توکن‌های طراحی، پوسته و استایل صفحه‌های بازی
- `docs/BACKEND.md` — ساختار پیشنهادی برای وقتی که حساب کاربری و بک‌اند اضافه شود

## امنیت و حریم خصوصی

- هیچ داده‌ای از دستگاه بیرون نمی‌رود؛ نه تحلیل‌گر، نه ردیاب، نه درخواست شبکه.
- `localStorage` تنها جای ذخیره است و همه‌ی داده‌های برگشتی با `sanitizeSave` اعتبارسنجی می‌شوند؛ داده‌ی قدیمی یا دست‌کاری‌شده دور ریخته می‌شود.
- صفحه با CSP محدود (`default-src 'self'`، بدون `connect-src`) اجرا می‌شود.
